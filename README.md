# 權益聰明切（Richart Point Switcher）

台新 Richart 卡「切換刷」試算小工具。睡前記錄當天實際刷卡的消費，工具會算出 23:59 前應該在 Richart Life App 切換到哪個方案，台新 Point 最多。

**網址：** https://xuancissus.github.io/richart-point-switcher/

> 個人試算工具，**非台新銀行官方服務**。實際回饋以台新銀行認定為準。

## 規則來源
- 台新銀行官網 Richart 卡權益頁、信用卡權益不回饋消費項目頁（2026/10/23 抓取）
- 權益期間 2026/7/1–2027/12/31。官網之後若有調整，工具不會自動更新
- 未列名店家的分類（例如手搖飲算「餐飲」）是推測，工具中會標示「推測」

## 隱私
- 你輸入的消費紀錄與自訂店家只存在**你自己瀏覽器的 localStorage**，不會上傳到任何伺服器
- 頁面不載入第三方資源（不使用 Google Fonts、沒有追蹤或分析程式）
